# 🚀 EaseYourNeeds Web

A powerful B2B SaaS web application designed to simplify and automate complex business needs. This platform offers robust Role-Based Access Control (RBAC) and secure authentication.

## ✨ Features
- **Secure Authentication**: Implementation of NextAuth with credential and OAuth providers.
- **Role-Based Access Control (RBAC)**: Strict permission handling for different user tiers.
- **Dynamic Dashboard**: Comprehensive data visualization for business metrics.

## 💻 Tech Stack
- Framework: Next.js, TypeScript
- Auth: NextAuth v5, bcryptjs
